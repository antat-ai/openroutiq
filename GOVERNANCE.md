# Governance

OpenRoutiQ uses a maintainer-led, consensus-seeking model.

- Contributors propose changes through issues and pull requests.
- Maintainers are responsible for security, releases, compatibility, evidence integrity, and repository moderation.
- Breaking routing semantics, persisted formats, or governance changes require a documented proposal and maintainer approval.
- Routine changes require one approving maintainer. Security releases may be prepared privately and merged without prior public discussion.
- Maintainer status is earned through sustained, high-quality contributions and sound judgment; existing maintainers decide additions or removals.

If consensus cannot be reached, the maintainers may defer the change, request more evidence, or document a final decision and rationale.
